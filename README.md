Description:
An interactive quiz game with timer-based questions, score tracking, and instant feedback for answers.

Technologies Used:
•	HTML 
•	CSS 
•	JavaScript 
•	DOM Manipulation 
•	Event Handling 
•	Timer Functions (setInterval)

Usage:
•	Users can start the quiz and answer multiple-choice questions within a time limit. 
•	Each question must be answered before the timer runs out or it auto-moves forward. 
•	Scores are updated in real-time based on correct answers. 
•	At the end, the final score is displayed and the quiz restarts automatically. 

Features :
•	Countdown timer for each question adds challenge and engagement. 
•	Instant feedback with color indicators for correct and wrong answers. 
•	Dynamic question loading with smooth transitions. 
•	Score tracking system with automatic quiz restart after completion.
